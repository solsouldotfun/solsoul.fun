# SolSoul Frontend

## Local Dev Quickstart

```bash
pnpm install
NEXT_PUBLIC_RPC_URL=http://127.0.0.1:8899 pnpm --filter app dev
```

Open:

- `http://127.0.0.1:3000/`
- `http://127.0.0.1:3000/launch`
- `http://127.0.0.1:3000/token/<mint>`

`NEXT_PUBLIC_RPC_URL` is optional and defaults to `http://127.0.0.1:8899`.
